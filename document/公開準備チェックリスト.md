# 公開準備チェックリスト（MVP v1）

## 1. Cloudflare Worker 設定

- `SAKURA_AI_API_KEY` を secret 登録
- `SAKURA_AI_MODEL` を vars または secret 登録
- `GOOGLE_MAPS_API_KEY` を secret 登録
- `APP_ORIGIN` を本番 URL へ設定
- `START_RATE_LIMIT` binding を設定
- `ALLOW_UNPROTECTED_START` が `false` であることを確認

## 2. Zone-level 保護（必須）

- Cloudflare WAF の rate limiting rule を `POST /api/navigation/start` に適用
- 初期値は `1 req / 10s / IP` を採用
- staging で Workers binding を使う場合でも、本番は zone-level ルールを主防御とする

## 3. API 動作確認

- `GET /api/health` が `200` を返す
- `POST /api/navigation/start` の `ok`, `no_match`, `validation_failed`, `upstream_error` を確認
- `Content-Security-Policy` などのセキュリティヘッダ付与を確認

## 4. 法務導線

- `/legal/privacy.html` と `/legal/terms.html` が公開されている
- アプリ画面からポリシーと規約へ遷移できる
- Google Maps attribution が案内画面に表示される

## 5. 実機確認

- iPhone Safari / Android Chrome で位置情報許可フローを確認
- 走行中の案内更新、off-route 判定、復帰判定を確認
- 音声案内（対応端末）と mute 切り替えを確認
- 画面スリープ周辺で wake lock の挙動を確認
